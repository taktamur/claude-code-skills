## 調査項目の詳細

### 除外する項目
以下の項目は基本的な概要調査では不要（ユーザーから明示的に要求されない限り除外）：
- ライセンス情報
- Stars数
- 最新バージョン
- オープンIssue/PR数
- 採用事例
- エコシステムの詳細
- パフォーマンスベンチマーク
- 導入方法の詳細

### 日本語サポートの調査ポイント
- UI/コンテンツの国際化機能の有無
- 日本語での検索機能（特にCJK言語のトークナイズ対応）
- 日本語公式ドキュメントの有無

### 想定Q&Aの作成ガイドライン
典型的な質問パターン：
1. どのような用途に適しているか？
2. 競合ツールとの選択基準は？
3. 他ツールからの移行は可能か？
4. パフォーマンスはどの程度か？
5. プロダクション実績はあるか？
6. 特定機能の制約への対処法は？
7. 日本語サイトを作成できるか？

## 出力フォーマット
- Markdown形式
- 箇条書きベース
- すべての情報に参考URL（根拠となるURL）を付与
- Q&Aは箇条書き形式（Q1とA1を改行で区切る）
