# 国立国会図書館サーチ 書影API

## 概要

国立国会図書館サーチ（NDLサーチ）の書影APIは、書籍のISBNまたはJP-eコードから書影画像（表紙画像）を取得できるAPI。

## URL形式

```
https://ndlsearch.ndl.go.jp/thumbnail/[ISBN13桁またはJP-eコード].jpg
```

## ISBNの形式

- **13桁**
- **ハイフンなし**
- 例: `978-4-7980-6853-4` → `9784798068534`

## 使用例

```markdown
![書籍名 表紙](https://ndlsearch.ndl.go.jp/thumbnail/9784798068534.jpg)

*書影：国立国会図書館サーチ 書影APIより*
```

## 利用条件

### 非営利目的
- 申請不要
- 個人ブログ、非営利サイトで使用可能

### 営利目的
- 要申請
- 広告収入のあるサイトなどは申請が必要

### クレジット表示
- **必須**: 書影使用時は必ずクレジット表示が必要
- 推奨表示: `*書影：国立国会図書館サーチ 書影APIより*`

## 返戻形式

- **成功時**: JPEG形式の画像を返す
- **失敗時**: HTTPステータスコード 404 Not Found
  - 存在しないISBN
  - 書影が未登録
  - 形式が不正

## エラーハンドリング

HTMLで使用する場合のonerror例：

```html
<img src="https://ndlsearch.ndl.go.jp/thumbnail/9784798068534.jpg"
     onerror="this.style.display='none'"/>
```

## データプロバイダ

- 出版情報登録センター（JPRO）から提供
- 定期的に更新される
- 最終刊行版と異なる場合や変更・提供中止となる場合がある

## 注意事項

- ISBNがない古い書籍では取得できない
- 電子書籍専用タイトルで取得できない場合がある
- 書影はキャッシュではなく定期的に再取得することを推奨
