# OSS Survey

OSS/ツールの概要調査を実施し、構造化されたMarkdownレポートを生成するClaude Codeスキルです。

## 機能

- 基本情報の収集（プロジェクト情報、技術スタック）
- 競合ツールとの比較分析
- 日本語サポート状況の調査
- 想定Q&Aの生成
- すべての情報に参考URLを付与

## 使い方

```
Astroの概要調査をして
```

## 出力

以下の構成でMarkdownレポートを生成します：

- **概要**: プロジェクト基本情報、技術概要
- **機能と競合比較**: 主要機能、対抗馬との比較、Googleトレンド、制約
- **想定Q&A**: 典型的な質問と回答
- **参考情報**: 公式ドキュメント、学習リソース、関連リンク

デフォルト保存先: カレントディレクトリ（`[ツール名]-概要調査.md`）
