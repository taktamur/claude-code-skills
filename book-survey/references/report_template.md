## タグの命名規則

**重要**: タグにスペースを含めてはいけない

✅ **使用可能**:
- `プログラミング`（1語）
- `書評`（1語）
- `technical-book`（ハイフン区切り）
- `TechnicalBook`（CamelCase）

❌ **使用禁止**:
- `プログラミング 入門`（スペース含む）
- `technical book`（スペース含む）

## 出典の形式

### 基本形式
```markdown
（[出典：ページタイトル](URL)）
```

### 同じ出典が連続する場合
```markdown
1. 項目1（[出典：ページタイトル](URL)）
2. 項目2（同上）
```

### 出典の配置ルール

同じ出典が連続しないように配置を調整：

❌ **悪い例**:
```markdown
1. メリット1（出典A）
2. メリット2（出典A）
3. メリット3（出典B）
```

✅ **良い例**:
```markdown
1. メリット1（出典A）
2. メリット2（出典B）
3. メリット3（出典A）
```

## ファイル名

形式: `YYYY-MM-DD-書籍名-評判調査.md`

例: `2025-12-30-プログラマー脳-評判調査.md`
