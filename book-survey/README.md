# Book Survey

書籍の評判を多角的に調査し、構造化されたMarkdownレポートを生成するClaude Codeスキルです。

## 機能

- ポジティブ・ネガティブ両面のレビュー収集
- 翻訳書は原題でも検索（海外レビュー収集）
- 国立国会図書館サーチAPIで書影取得
- すべての評価に出典を付与

## 使い方

```
「プログラマー脳」という書籍の評判を調査して
```

## 出力

以下の構成でMarkdownレポートを生成します：

- 📚 書籍概要（著者、出版社、ISBN、価格、表紙画像）
- ✅ ポジティブな評価
- ⚠️ ネガティブな評価・注意点
- 📊 総評（対象読者、注意点）
- 📝 参考リンク

デフォルト保存先: `~/bot-diary/YYYY-MM-DD-書籍名-評判調査.md`
