# github-repo-jobutsu

privateかつarchive済みのGitHubリポジトリを調査し、Scrapbox形式の記事として成仏させるスキル。

## 機能

- privateかつarchive済みリポジトリの一覧取得・選択
- リポジトリのクローン・調査（README、ファイル構成、コミット履歴、コアソース抽出）
- Scrapbox形式の記事生成・クリップボードコピー

## 使い方

```
「ネタ成仏して」
「アーカイブリポジトリを調べて」
「GitHubのリポジトリを整理して」
```

## 出力

Scrapbox形式のテキスト（クリップボードにコピー）。リポジトリ名、作成日、技術キーワード、概要、コアソースを含む。

## 技術詳細

- `gh` CLI でリポジトリ一覧取得・クローン
- `pbcopy` でクリップボードにコピー
- 作業ディレクトリ: `~/tmp/github-repo-jobutsu/`
