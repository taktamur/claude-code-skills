# Fallout New Vegas Mod カテゴリーリファレンス

Nexus ModsのFallout New Vegasで利用可能な主要カテゴリーの一覧。

## 全カテゴリー一覧

### Player Homes (803 files)
プレイヤーハウス、セーフハウス、拠点などのMod。

**人気のサブカテゴリー・キーワード:**
- Underground/Vault - 地下施設・Vault
- Mobile/Portable - 持ち運び可能
- Apartment - アパート
- Ranch/House - 牧場・家
- Suite - スイートルーム

### Weapons (5,888 files)

**サブカテゴリー:**
- 銃器（ライフル、ピストル、ショットガンなど）
- 近接武器
- エネルギー武器
- 爆発物

**「バグ修正Modを探して」**
→ Bug Fixes

**「コンパニオンを探して」**
→ Companions

**「UIを改善したい」**

**「ゲームバランスを変更したい」**
→ Gameplay Effects and Changes, Overhauls

**「パフォーマンス改善」**
→ Performance

## 検索キーワードの例

### Player Homes関連
- `portable` - 持ち運び可能
- `mobile` - 移動可能
- `summon` - 召喚可能
- `vault` - Vault型
- `apartment` - アパート型
- `underground` - 地下施設
- `luxury` - 豪華な
- `storage` - ストレージ重視
- `workshop` - ワークショップ完備

### Weapons関連
- `rifle` - ライフル
- `pistol` - ピストル
- `energy` - エネルギー武器
- `melee` - 近接武器
- `explosive` - 爆発物
- `realistic` - リアル志向

### Graphics関連
- `retexture` - リテクスチャ
- `HD` - 高解像度
- `realistic` - リアル志向
- `immersive` - 没入感

## 注意事項

- カテゴリー内のファイル数は変動する可能性がある
- 複数のカテゴリーに該当するModもある
- 検索結果が多すぎる場合はソート順を変更して絞り込む
