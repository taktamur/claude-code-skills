# Claude Code Skills

[Claude Code](https://claude.com/claude-code)で使用できるスキルのコレクションです。

## 公開スキル

| スキル名 | 説明 |
|---------|------|
| [book-survey](book-survey/) | 書籍の評判を多角的に調査し、構造化されたMarkdownレポートを生成。ポジティブ・ネガティブ両面のレビュー収集、国立国会図書館APIで書影取得。 |

## スキルの使い方

各スキルのディレクトリをClaude Codeのスキルフォルダ（`~/.claude/skills/`）に配置してください。

```bash
cd ~/.claude/skills/
git clone https://github.com/taktamur/claude-code-skills.git
cp -r claude-code-skills/book-survey ./
```

または、個別のスキルディレクトリを直接コピーすることもできます。
