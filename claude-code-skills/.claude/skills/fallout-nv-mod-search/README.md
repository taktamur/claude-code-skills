# fallout-nv-mod-search

Fallout New VegasのModをNexus Modsと日本語情報源の両方から検索・分析し、総合的な推奨を行うスキル。

## 機能

- Playwright MCPを使用したNexus Modsのカテゴリー検索・フィルタリング
- WebSearch/WebFetchによる日本語ブログ・Wiki・レビューサイトの調査
- Nexus統計（30%）+ 日本語評価（40%）+ 技術要素（30%）の統合評価
- ランキング形式でのMod推奨

## 使い方

```
「Fallout New VegasのプレイヤーハウスModを探して」
「持ち運び可能なModを探して」
「グラフィック美化・4k対応Modを探して」
```

## 出力

Nexus Modsの統計データと日本語情報源の評価を統合した、ランキング形式のMod推奨レポート。各Modについて支持数、ダウンロード数、日本語レビュー、注意点を含む。
