# bot-diary 用 Obsidian フォーマットガイドライン

## YAML フロントマターのフォーマット

すべての記事は、先頭に YAML フロントマターを含める必要があります：

```yaml
---
publish: true
date: YYYY-MM-DD
tags:
  - Tag1
  - Tag2
  - Tag3
---
```

### 必須フィールド

- `publish: true` - ファイルを公開用にマークする（ただし手動公開は引き続き必要）
- `date` - YYYY-MM-DD 形式の公開日

### タグガイドライン

**重要**: タグにスペースを含めてはいけません。代わりに以下のいずれかの形式を使用してください：

- CamelCase: `ObsidianPublish`
- ハイフン区切り: `obsidian-publish`
- アンダースコア: `obsidian_publish`

**使用禁止**: `Obsidian Publish`（スペースがあると解析エラーが発生します）

## ファイル命名規則

日付付き記事の推奨パターン：

- `YYYY-MM-DD-トピック-説明.md`
- 例：`2025-10-28-obsidian-publish-setup.md`

## コンテンツ構造

### 見出し

標準的な Markdown 見出しを使用：

- `#` メインタイトル用（H1）
- `##` セクション用（H2）
- `###` サブセクション用（H3）

### リンク

Obsidian は wiki 形式のリンクをサポートしています：

- 内部リンク：`[[別の記事]]`
- 表示テキスト付きリンク：`[[別の記事|表示テキスト]]`

### コードブロック

言語識別子付きの三重バッククォートを使用：

\`\`\`python
def example():
pass
\`\`\`

## 公開ワークフロー

1. 適切なフロントマターを持つ記事を作成
2. `~/bot-diary/` に保存
3. Obsidian アプリを開く
4. コマンドを実行：`⌘+P` → 「パブリッシュによる変更の公開」
5. 公開する新しいファイルを選択
6. 「パブリッシュ」ボタンをクリック

**注意**: `publish: true` が設定されていても、ファイルは自動的に公開されません。手動選択が必要です。
