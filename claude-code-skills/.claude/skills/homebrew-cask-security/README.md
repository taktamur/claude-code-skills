# homebrew-cask-security

Homebrew caskの定義ファイルを取得・分析し、インストール前に悪意のあるコードや疑わしい設定がないかをセキュリティチェックする。

## 機能

- Homebrew公式リポジトリからcask定義ファイルを自動取得
- セキュリティ観点での体系的な分析（SHA256ハッシュ、スクリプト、ダウンロード元の確認）
- リスク評価レポートの生成（安全な要素、注意が必要な要素、危険な要素を分類）
- 開発者・企業の信頼性確認（公式サイト、レビュー、評判の調査）
- インストール後の検証手順の提供

## 使い方

ユーザーが以下のようにリクエストした場合に自動的に起動：

```
brew install --cask [app-name]のセキュリティをチェックして
```

または、特定のcask名を指定：

```
[app-name]のcask定義に悪意があるか確認して
```

## 出力

セキュリティ評価レポートを以下の形式で出力：

- **✅ 安全と判断できる要素**: SHA256ハッシュの存在、シンプルなインストール処理など
- **⚠️ 注意すべき点**: カスタムスクリプト、PKGインストーラー、自動更新など
- **🔍 Cask定義の分析結果**: 重要部分の抜粋と解説
- **📊 総合評価**: リスクレベル（低/中/高）と推奨事項
- **💡 推奨事項**: インストール前後の確認コマンド

## セキュリティチェック項目

### 安全性の高い要素

- SHA256ハッシュによるファイル整合性検証
- シンプルな `app` インストール
- 標準的なzap設定（アプリケーションデータの削除パス）
- Homebrew公式リポジトリに収録
- verified ドメイン

### 注意が必要な要素

- カスタムスクリプト（preflight, postflight）
- PKGインストーラー
- 自動更新設定
- sudo権限を必要とするアンインストール
- 非標準のダウンロード元

### 危険な要素（レッドフラグ）

- SHA256ハッシュの欠如（`:no_check`）
- システムディレクトリへの書き込み
- 不審なダウンロード元（個人のDropbox、IPアドレス、HTTPプロトコル）
- 過度な権限要求
