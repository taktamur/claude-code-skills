# scrapbox-monthly-page

Scrapbox用の月次ページを生成するスキル。指定した年月の全日付と曜日をScrapboxリンク形式で出力します。

## 機能

- 指定年月の全日付を日本語曜日付きで生成
- Scrapboxリンク形式での出力
- 前月・翌月へのナビゲーションリンク自動生成

## 使い方

```bash
python3 scripts/generate.py YYYY-MM
```

例:
```bash
python3 scripts/generate.py 2025-01
```

## 出力

```
2025/01
[2024/12] ← →[2025/02]

[2025/01/01](水)
[2025/01/02](木)
...
[2025/01/31](金)
```

出力されたテキストをScrapboxページに貼り付けるだけで、月次カレンダーページが完成します。
